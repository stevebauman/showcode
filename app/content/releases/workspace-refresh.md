**Added**

- Added floating editor and preview toolbars with language, editor settings, copy, export, fit, and zoom controls
- Added a collapsible inspector with Style, Themes, Backdrop, and Scenes controls
- Added visual choices for workspace layout and window position
- Added desktop release announcements that appear once after an update and can be reopened from Help
- Added native desktop menus, file dialogs, image export, and clipboard support

**Changed**

- Refreshed the window structure, project tabs, settings popovers, and form controls
- Added smooth editor reordering while preserving resizable dividers
- Expanded canvas zoom with typed percentages and additional presets
- Aligned hover and keyboard focus styling across the application
- Simplified the loading screen to the logo and loading indicator

**Fixed**

- Fixed clipping around rounded changelog cards
- Fixed toolbar overflow and spacing in smaller windows
